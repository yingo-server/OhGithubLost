# OGL 设计系统 v2（自研）· 代号「Spatial」

> 目标（产品决策）：**通用性第一，性能第二；大气、简洁。**
> Material Design 3 为**官方次选主题**；本设计系统为**默认风格**。
> 方法论来源：`.skills/flutter-ai-ui-skill`（设计系统生成流程）+ 本项目 `SURFACE.md` 界面法则。
> 本文件是 UI v2 重写的**唯一设计真源**；代码落地为新的默认主题包 `ogl.spatial`。

---

## 0. 设计原则（五条，冲突时按序取舍）

1. **通用性第一**：同一套界面必须同时成立在 手机竖/横屏 · 平板 · 桌面（窗口任意尺寸）· 低高 DPI · 键盘/触控/鼠标。
2. **性能第二**：所有视觉决策必须先在性能预算里通过（见 §7）；宁可少一层模糊，不多一帧重绘。
3. **大气**：大留白、低饱和、强层级；用**空间**而不是颜色表达结构。
4. **简洁**：每屏只允许一个视觉焦点；删掉一切可删的装饰。
5. **平静的深度**：以**描边**为主、阴影为辅；不做夸张投影与霓虹渐变。

## 1. 颜色令牌（双模，语义命名，不允许页面直接取值）

| 令牌 | 深色（默认） | 浅色 | 用途 |
|---|---|---|---|
| `bg` | `#0B0E13` | `#F7F8FA` | 应用底色（最深远） |
| `surface` | `#12161D` | `#FFFFFF` | 卡片 / 面板 |
| `subtle` | `#181E27` | `#F0F2F5` | 次级面板 / 输入框底 |
| `elevated` | `#1C232E` | `#FFFFFF` | 悬浮层（菜单/对话框） |
| `outline` | `#2A3442` | `#D8DDE5` | 1px 描边（发丝线） |
| `text` | `#E8ECF2` | `#1A1F26` | 主文本 |
| `textDim` | `#9AA6B5` | `#5A6572` | 次文本 |
| `textFaint` | `#5C6B7E` | `#8A94A3` | 弱文本 / 元信息 |
| `accent` | `#4C8DFF` | `#2F6FEB` | 唯一强调色（链接/选中/主按钮） |
| `success` | `#4CC38A` | `#1F9D61` | 成功 |
| `warning` | `#E5A50A` | `#B07A00` | 告警 |
| `danger` | `#F2555A` | `#D03036` | 错误 / 危险 |

> 规则：同一屏 `accent` 出现面积 ≤ 8%；状态色只用于状态，不做装饰。

## 2. 间距（4dp 栅格，与现令牌一致）

```
xxs 2 · xs 4 · sm 8 · md 12 · lg 16 · xl 24 · xxl 32 · huge 48
```
规则：组件内间距用 sm/md；组件间用 lg/xl；页面级留白用 xl/xxl（桌面端 xxl/huge）。

## 3. 圆角与描边

```
r-xs 4（输入/徽标）· r-sm 8（按钮/行内）· r-md 12（卡片）· r-lg 16（面板/抽屉）· r-full 999（胶囊）
```
- 描边统一 **1 物理像素发丝线**（已有 `hairline` 引擎）；聚焦态 = `accent` 描边 + 2px 光晕（仅输入类）。
- 阴影仅两级：`e1` = 0/1dp（悬浮菜单）；`e2` = 0/2dp（对话框）。卡片默认**无阴影**。

## 4. 字阶（紧凑而清晰）

| 级别 | 字号/行高/字重 | 用途 |
|---|---|---|
| Display | 28 / 36 / 600 | 空态大标题（极少用） |
| Title-L | 20 / 28 / 600 | 页面标题 |
| Title-M | 16 / 24 / 600 | 卡片标题 |
| Body | 14 / 22 / 400 | 正文 |
| Body-S | 13 / 20 / 400 | 次级说明 |
| Label | 12 / 16 / 500 | 元信息 / 徽标 |

等宽族仅用于哈希 / 分支名 / 代码（`monospace` 系统字体，零外部资源）。

## 5. 动效（克制，仅三处允许）

- 标准曲线 `Curves.easeOutCubic`；时长：**120ms**（微反馈）· **180ms**（面板/导航切换）· **240ms**（对话框）。
- 只允许：① 状态变化淡入淡出；② 导航/分栏切换的水平位移；③ 展开/折叠尺寸过渡。
- 禁止：循环动画（加载指示器除外）、视差、粒子、发光脉动。尊重系统"减少动效"开关（已归零接入）。

## 6. 组件规范（v2 四件套）

1. **卡片 Card**：`surface` 底 + 发丝描边 + r-md；内边距 lg；标题 Title-M，描述 Body-S。
2. **列表行 Row**：高 56（紧凑 48）；左图标 20px·textDim；主文本 Body；右侧元信息 Label·textFaint；点击区整行。
3. **表单 Form**：输入底 `subtle`、描边 `outline`、聚焦 `accent`；错误文案 `danger`·Label；标签浮于上缘。
4. **四态视图**：加载=线性指示器居中；空=图标+一行说明+主行动按钮；失败=原因+重试；就绪=内容。全部复用现有 `OgLAsyncView` 纪律。

## 7. 性能预算（硬性）

- 每屏 `const` 子树最大化（现基线：全仓 423 处 const）；列表项禁止闭包内建大对象。
- 列表一律 `itemExtent` 或原型项；>100 项必须懒加载。
- 滚动容器与动画边界加 `RepaintBoundary`（快照测试已覆盖 12 形态）。
- 纹理/模糊总预算：**每屏 0 个大面积 BackdropFilter**（这是性能最大杀手，直接禁用）。
- 帧预算 16.6ms；字体全部系统字体（零外部资源不变）。

## 8. 通用性矩阵（必须同时成立）

| 维度 | 覆盖 |
|---|---|
| 手机竖/横 | 底栏 + 单栏；横屏自动分栏（复用布局引擎） |
| 平板 | NavigationRail + 列表/详情（600–840 窄轨，840+ 宽轨） |
| 桌面 | 宽轨 + 三栏（1200+）；鼠标悬停/拖拽滚动（已有） |
| 输入 | 触控 / 鼠标 / 键盘（Ctrl+1..9、R、K、, 、Esc 已有） |
| DPI | 发丝线=1 物理像素；图标 20/24 物理对齐 |
| 无障碍 | 触摸目标 ≥44；文字缩放 0.85–2.0；图标按钮必带 tooltip（语义） |

## 9. 与 Material 3 的关系

- **自研 Spatial = 默认**；MD3 = 官方次选主题（保留完整 token 映射，随时切换）。
- 两套主题共用同一令牌接口（`OgLTheme` extension），页面永不感知当前主题。

## 10. 落地步骤（对应代码改造顺序）

1. `theme_pack.dart` 新增 `ogl.spatial` 包（本规格 → 令牌），并设为默认；
2. `og_l_app.dart`：概览+日志并入「系统」页，导航收敛为 仓库/设置/系统；
3. 组件四件套落到 `surface/app/`（卡/行/表单/四态）；
4. 仓库页按 v2 规范重绘；桌面三栏用 `OgLShellFrame` 正式接线（消灭双外壳）；
5. 12 张快照重出 → 人工比对 → CI 全绿。
