# L3 展示层 · 界面法则（SURFACE）

> 用途：**写任何界面之前先读它**。本文件里的每一条都有对应测试，
> 违反其中任意一条都会被 CI 拦下（`test/surface/*`）。
> 状态：**L3 地基已完成并 CI 全绿**（run `36817331238`，321 项测试）。

---

## 一、三层收口：界面只消费结论，不做尺寸决策

```
MediaQueryData + 平台
        ↓  SurfaceBridge.viewportOf()
   OgLViewport        ← 环境事实（DPI / 安全区 / 键盘 / 文字缩放 / 指针）
        ↓  .spec
   OgLLayoutSpec      ← 布局结论（导航形态 / 分栏 / 列数 / 内容宽度）
        ↓  SurfaceBridge.themeFor()
    ThemeData + OgLTheme（ThemeExtension）
        ↓
      页面 Widget
```

**铁律**：页面里**不允许**出现 `MediaQuery.of(context).size.width > 600`、
不允许硬编码 `16.0` 间距、不允许直接写 `Colors.red`。
一律改成读 `OgLTheme.of(context).layout / .tokens / .colorFor(...)`。

## 二、不可违背的法则

### 2.1 布局
| 法则 | 原因 |
|---|---|
| 断点只有 **600 / 840 / 1200** | 分散的断点必然导致"这个页面切了、那个页面没切" |
| 导航形态自动切：`<600` 底栏（移动）/ 抽屉（桌面）→ `<1240` 窄轨 → `≥1240` 宽轨 | 把移动端底栏塞进桌面窗口是习惯误用 |
| 分栏自动切：`<720` 单栏 → `<1100` 列表详情 → 三栏 | 用户不必自己算"屏幕够不够宽" |
| **列数与栏数对宽度严格单调** | 拖窗口时"列数回退"会表现为闪烁；已有回归测试 |
| 网格瓦片宽度按**窗口宽度**分级，不按设备形态 | 跟设备形态走会破坏单调性（真踩过） |

### 2.2 DPI 与可访问性
| 法则 | 原因 |
|---|---|
| 分割线一律用 `tokens.hairline`（= 1 物理像素） | DPR=3 时写 `1` 会得到 3 像素粗线，显脏 |
| 设备尺寸判定用 **dp 模型**（`√(w²+h²)/160`） | dp 已密度无关；再乘除 DPR 等于把密度算两遍 |
| 文字缩放夹紧在 `[0.85, 2.0]` | 系统给 3 倍时布局必然溢出，夹紧 + 主动截断比错位好 |
| 触摸设备最小点击目标 **≥ 44**（`compact` 也不破例） | 可访问性底线，不给"信息密度"让路 |
| 系统"减少动态效果" ⇒ 所有时长归零 | 无障碍开关凌驾于审美偏好 |

### 2.3 主题与图标
| 法则 | 原因 |
|---|---|
| `ThemeData` **只允许在 `buildOgLTheme` 里构造** | 否则主题切换会漏掉某些角落 |
| 取色只能走 `OgLPalette` / `colorFor(OgLSemanticColor)` | 状态色收敛到一处，避免各页各写红绿 |
| 图标只能引用 `OgLIconName`（语义），不能写 `Icons.xxx` | 换图标包 = 换一个 id，零处改动；`switch` 编译期强制三套包齐全 |
| 新增语义图标名 ⇒ **必须补齐全部图标包** | 编译器会拦；这是特性不是负担 |
| 用户自定义强调色**必须真的生效** | 存了不用的设置 = "点了没反应" |

> ⚠️ 关于 Font Awesome：`font_awesome_flutter` 建立在 `extends IconData` 之上，
> 而 Flutter 3.47 起 `IconData` 是 `final class`，**任何版本都无法编译**。
> 若要引入，正确做法是自带 ttf + 手写 `IconData(codePoint, fontFamily:)` 表
> （只实例化、不继承）。

### 2.4 权限（跨平台）
| 法则 | 原因 |
|---|---|
| **每一条权限必须写清 `consequence`（失去它会怎样）** | 不允许"点了没反应" |
| **核心流程零权限依赖**：所有规则都是 `degrade`，无一 `block` | 浏览公开仓库必须永远可用 |
| `systemSettingsOnly` 必须给 `settingsHint`（具体路径） | 只让用户"去设置里开"却不说是哪，等于没说 |
| 状态**未知 ⇒ 按不可用处理**（绝不猜成"已授权"） | 猜成已授权会在真正调用系统 API 时才炸 |
| 未知平台 / 矩阵外权限 ⇒ `notRequired` | **不假装知道**，宁可少要不可多要 |

### 2.5 设置与开发者选项
| 法则 | 原因 |
|---|---|
| 默认值必须是最保守的一档（批量必问 / 通道每次问 / 开发者模式关） | 默认值就是产品态度 |
| **危险开关受"开发者模式"总闸控制**：关总闸即清空全部开关 | 避免"看着关了其实还开着" |
| 手改配置文件**也不能**进入危险状态（`sanitize` 强制拧回） | 配置文件不是后门 |
| 数值项一律夹紧（缓存条目 `[64, 8192]`、TTL `[0, 3650]`） | 越界值只会在运行时炸 |
| 反序列化**永不抛**，被修正的字段进 `lastRepairs` | 坏配置要让应用照常启动并可追溯 |
| 保存失败 ⇒ **本次改动仍生效**，但如实告知"重启会丢" | 点了没反应比"提示会丢"更糟 |

## 三、动效的分寸

只保留 4 档且都偏短：`fast 90ms`（hover/press）、`base 160ms`（切换）、
`slow 240ms`（面板展开）、`slower 360ms`（换页面）。

**判据**：动画的职责是"让界面不显得死板"，不是"表演"。
超过 400ms 的过场只会让高频操作变慢。极客风主题连水波纹都关闭
（`NoSplash`），因为"扩散的圆"与 1px 描边语言冲突。
