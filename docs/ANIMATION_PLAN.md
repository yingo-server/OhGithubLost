# 3.2 动画任务与性能对应

本文件是 3.2 的全部动效任务清单，并说明「动画效果 ↔ 性能消耗 ↔ 档位」的对应关系。

## 一、效果与性能对应

档位越高，叠加的效果越多，开销越大；档位 `0` 一律关闭。

| 档位 | 入场效果 | 时长（入场） | 列表错峰 | 页面过渡 | 相对开销 |
| --- | --- | --- | --- | --- | --- |
| 0 | 无（直接显示） | 0 | 0 | 即时 | 无 |
| 1 | 仅淡入（Opacity） | 180ms | 20ms×n（封顶 6） | Flutter 默认 | 低 |
| 2 | 淡入 + 位移（Opacity + Slide） | 240ms | 40ms×n | Zoom | 中 |
| 3 | 淡入 + 位移 + 缩放（+ Scale） | 300ms | 60ms×n | 增强（淡入 + 位移 + 缩放） | 高 |

控制措施：

- 列表错峰的序号**封顶 6 项**，长列表不会越等越久；
- 入场只对**首屏项**执行（列表项挂载时播放），滚动到的新项不再重复；
- 只用透明度 / 位移 / 缩放，**不改变布局尺寸**（避免重排与抖动）；
- 缩放仅出现在档位 `3`，把最贵的效果留给明确选择高动效的用户。

## 三、纪律

- 只做「有信息量」的动画：过渡、入场、状态变化；不做循环动效；
- 所有动画必须可被档位 `0` 关闭；
- 不引入第三方动画库（只用 Flutter 自带 `AnimatedXxx` / `Tween`）；
- 新增动画必须补测试：档位 `0` 关闭、档位递增、回退为零。

## 四、验收

- 档位 `0`：无动画层、时长为零；
- 档位 `1`/`2`/`3`：时长与叠加效果递增；
- `flutter analyze --fatal-infos` 与 `flutter test` 通过。
