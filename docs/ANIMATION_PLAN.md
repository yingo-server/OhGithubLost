# 动画规划（3.2）

本文件规划 3.2 的动效改造，与设置里的「动效档位」联动。

## 一、四档位语义

设置项 `motionLevel`（0–3）已存在，含义如下：

- `0` 最小：关闭动画（`disableAnimations` 置真），页面切换即时；
- `1` 当前：沿用既有行为（尊重系统「减少动效」），过渡短促；
- `2` 标准：采用较明显的过渡与入场；
- `3` 增强：在标准之上叠淡入、位移与缩放。

实现原则：**动画只在档位允许时执行**；档位 `0` 通过 `MediaQuery.disableAnimations`
统一关闭，控件无需各自判断。

## 二、动画工具箱

新增 `lib/surface/app/animations.dart`：

- `OgLReveal`：入场淡入 + 轻微上移，用于列表项与卡片；
- `OgLAnim`：按档位给出时长（快 / 中 / 慢），供控件复用；
- 全部走 `MediaQuery.disableAnimations`，档位 `0` 自动失效。

## 三、覆盖范围（分阶段）

第一批（3.2）：

- 首页仓库列表项：逐项入场；
- 下载管理、通知中心、草稿箱列表：逐项入场；
- 进度条：`LinearProgressIndicator` 的数值变化使用隐式动画；
- 卡片展开 / 折叠：沿用 `ExpansionTile` 自带动画，统一时长。

第二批：

- 仓库页代码列表、议题 / PR 列表入场；
- 段选（`SegmentedButton`）切换的轻微位移；
- 设置页分组标题的点击反馈；
- 对话框 / 底部弹出的入场曲线统一。

第三批：

- 页面切换的共享元素（文件图标 → 文件详情）；
- 空态 / 错误态之间的淡入淡出（`AnimatedSwitcher`）。

## 四、纪律

- 只做「有信息量」的动画：过渡、入场、状态变化；不做无意义的循环动效；
- 所有动画必须可被档位 `0` 关闭；
- 动效不得改变布局尺寸（只用透明度与位移 / 缩放，避免抖动）；
- 长列表的入场只对**首屏可见项**执行，滚动新增项不再重复播放入场。

## 五、验收

- 档位 `0`：无动画；档位 `1`/`2`/`3`：过渡时长递增；
- `flutter analyze --fatal-infos` 与测试通过；
- 不引入第三方动画库（沿用 Flutter 自带 `AnimatedXxx` 与 `Tween`）。
