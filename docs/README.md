## 约定

- **发布说明**放在根目录 [`release_notes/`](../release_notes)，每版本一个文件；
- **完整版本历史**在根目录 [`CHANGELOG.md`](../CHANGELOG.md)；
- 本目录只放"持续有效"的手册类文档；一次性规划落地后即移除，不留僵尸文档；
- 文档里点到的符号必须**真实存在**（改名时一并更新），路径尽量写成可点击链接。
