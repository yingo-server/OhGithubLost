
## 3. 推送策略（硬性）

1. 每波收口**一次** push（代码 + 检查 + 文档 同批）；
2. push 后等 **CI 绿** 才进下一波；CI 红则修复后重推同一波；
3. **开发期不等构建**（build 随 push 自动跑，不阻塞推进；W5 收口时统一核 13/13）；
4. 推送**前 / 后各备份 1 份** tar.gz 到 `_backup/`（命名含波次与时间）；
5. 每波收口**更新记忆档案**（状态卡：波次 / commit / CI / 下一波）。
