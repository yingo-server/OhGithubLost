## OhGithubLost 1.4 · 正式版 / Stable

**主题 · Theme** — 设置中心细化、零依赖代码高亮、仓库浏览增强、议题评论与权限网关。
*Settings depth, dependency-free syntax highlighting, richer repository browsing, issue comments and a permission gateway.*

### 新增 · Added

- **设置中心细化 · Deeper settings**
  主题色、界面密度、文字缩放、减少动效；代码高亮、代码字号、自动换行、目录优先排序——每一项都接到真实行为。  
  Theme colour, density, text scaling and reduced motion; code highlighting, code font size, soft wrap and directories-first sorting — every switch is wired to real behaviour.
- **代码语法高亮 · Syntax highlighting**
  零第三方依赖的 `CodeView`：超大文件自动退回纯文本，海量行不渲染行号（极端输入不崩）。  
  A dependency-free `CodeView`: very large files fall back to plain text and huge files skip line numbers, so extreme inputs do not crash.
- **仓库浏览增强 · Repository browsing**
  文件夹优先排序；按语言区分文件图标；长按 / 右键菜单支持**下载 / 详情 / 删除**。  
  Directories sort first, file icons reflect the language, and a long-press/right-click menu offers download, details and delete.
- **议题评论 · Issue comments**
  可直接在议题页发表评论，含长度护栏与可见错误。  
  Comment directly on an issue with a length guard and visible errors.

### 变更 · Changed

- **首次引导与跨平台权限网关 · Onboarding and permission gateway**
  按 Android / iOS / macOS / 桌面 / Web 分派；**刻意不引入 `permission_handler`**（避免当时破坏 CI 构建链），权限状态如实呈现。  
  Dispatched per platform (Android / iOS / macOS / desktop / web). `permission_handler` was deliberately avoided at the time to keep the CI build chain intact; permission state was reported honestly.

### 已知限制 · Known limitations

- 该权限网关**不会调起系统权限弹窗**（只做状态呈现与跳转设置），因此在 Android 上无法真正取得存储权限——4.0.0 已改用 `permission_handler` 解决。  
  This gateway never triggered real system permission prompts (it only reported state and opened settings), so storage permission could not actually be obtained on Android; 4.0.0 fixed this with `permission_handler`.
- 令牌仅保存在本机安全保险库；仓库数据只与 GitHub 通信。  
  Tokens are stored only in the device’s secure vault, and repository data is exchanged with GitHub alone.
