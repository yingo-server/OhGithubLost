## OhGithubLost 2.0.0 · 正式版 / Stable

**主题 · Theme** — Actions / Gist 完整化、浏览体验细化，以及一次重要的**发布工程修复**。
*Completing Actions and Gists, refining browsing — plus an important release-engineering fix.*

### 新增 · Added

- **Actions 完整化 · Complete Actions**
  运行详情（作业 + 每一步状态）、状态筛选、**重新运行 / 取消**。  
  Run details (jobs and per-step status), status filtering, and re-run/cancel.
- **Gist 完整化 · Complete Gists**
  查看（语法高亮）/ 新建 / 编辑 / 删除；内容被截断时自动回退 raw。  
  View (with highlighting), create, edit and delete; truncated content falls back to raw automatically.
- **议题评论**布局改为规范时间线卡片；**仓库浏览**切换目录先清空旧数据并显示路径面包屑。  
  Issue comments follow a proper timeline-card layout; browsing clears stale data when changing directories and shows a breadcrumb.
- **代码高亮**新增预设：跟随主题 / 高对比 / 柔和 / 自定义（可逐项选色）。  
  Highlight presets: follow theme, high contrast, soft, and custom (per-token colours).
- **文件图标**按语言 / 类型更准确（对齐 GitHub Linguist 色彩）。  
  File icons follow language/type more accurately, matching GitHub Linguist colours.
- **多用户 · Multi-account**
  切换 / 移除账号时刷新会话并清空一致性缓存，避免跨账号串台。  
  Switching or removing an account refreshes the session and clears the consistency cache so accounts never see each other’s data.

### 修复 · Fixed（发布工程 · Release engineering）

- 发布参数 `version_name` / `version_number` **改为必填、删除默认值**：旧版默认 `0.1.0`，一旦漏填就会产出 0.1.0 的包（APK 显示 0.1.0，而应用内版本来自代码常量，看起来“正常”，极难发现）。  
  `version_name` and `version_number` are now mandatory with their defaults removed: the old default was `0.1.0`, so a forgotten value silently produced 0.1.0 builds that looked fine because the in-app version comes from a code constant.
- **所有平台统一注入版本号**（旧版只给 Android，Windows/Linux/macOS/iOS 会停在 pubspec 版本，跨平台不一致）。  
  All platforms now receive the injected version; previously only Android did, leaving desktop/iOS at the pubspec version and inconsistent across platforms.
- 新增 **Android versionName 护栏**：逐个 APK 校验 versionName 与发布版本一致，不一致直接失败，杜绝 0.1.0 事故回归。  
  Added an Android versionName guard that checks every APK and fails the build on mismatch, preventing any recurrence of the 0.1.0 incident.
- 版本统一：pubspec `2.0.0+20000`，应用内 `kOgLAppVersion = 2.0.0`。  
  Version aligned: pubspec `2.0.0+20000`, in-app `kOgLAppVersion = 2.0.0`.

### 已知限制 · Known limitations

- **多语言（R6）尚未开始**：界面为中文。  
  Localisation (R6) has not started yet — the UI is Chinese-only.
