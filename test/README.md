# test · 测试目录

按四层架构分目录；全部测试**离线运行**（不依赖网络 / 真机）。

| 目录 | 覆盖 |
| --- | --- |
| `kernel/` | 引导清单签名 / 信任链 / 装配 / 生命周期 / 环境自检 |
| `base/`   | 磁盘（原子写 / 路径 / 三档分级 / 缓存七道防线 / 持久化 / 破坏性测试）、网络（重试 / 镜像 / 分片） |
| `domain/` | GitHub 客户端与端点语义（空 / 无 / 未启用 ⇒ "没有"）、本地深层信息守门 |
| `surface/`| 设置容错 / i18n 完整性 / 动效分级 / 页面过渡 / 返回键 / 权限网关 / README 渲染 / 冒烟 |
| `screenshots/` | UI 截屏矩阵（`OGL_SCREENSHOTS=1` 时落盘样本） |

运行：`flutter test`（CI 质量门之一）。
