## OhGithubLost 1.1.0 · 正式版 / Stable

**主题 · Theme** — **密钥全量轮换（v2）**：引导签名钥与 Android 签名证书全部替换。
*Full key rotation (v2): both the boot-signing key and the Android signing certificate were replaced.*

### 变更 · Changed

- 引导签名钥（Ed25519）+ Android 签名证书全部替换为第二代密钥。  
  The boot-signing key (Ed25519) and the Android signing certificate were both rotated to generation 2.
- **私钥不再入库**：CI 构建时从 GitHub Actions Secrets 还原，仓库里不留任何私钥材料。  
  Private keys are no longer committed — CI restores them from Actions Secrets, so no key material lives in the repository.
- 版本号对齐：pubspec 与应用内版本均为 `1.1.0`。  
  Version aligned: both pubspec and the in-app constant read `1.1.0`.

### 安装注意 · Installation note

> **v1.0.0 及更早版本请先卸载一次**（签名证书已更换，无法覆盖安装），之后即可正常覆盖升级。  
> **Uninstall v1.0.0 and earlier once** — the signing certificate changed, so an in-place update is impossible. After that, over-the-air updates work normally.
