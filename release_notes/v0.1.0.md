## OhGithubLost 0.1.0 · 预发布 / Pre-release

**主题 · Theme** — 首个公开发布：Linux 内核式分层架构的 GitHub 第三方客户端（Flutter 全平台）。
*The first public release: a GitHub client with a Linux-kernel-style layered architecture, built with Flutter for every platform.*

### 新增 · Added（核心能力 · Core capabilities）

- **登录 · Sign-in**：个人访问令牌向导 + 游客模式。  
  Personal access token wizard plus a guest mode.
- **首页 · Home**：我的仓库 / 星标仓库 / 新建仓库。  
  My repositories, starred repositories and repository creation.
- **搜索 · Search**：仓库与代码双通道。  
  Repository and code search channels.
- **仓库全功能 · Full repository support**：文件浏览与编辑提交；议题（新建 / 评论 / 关闭）；Pull Request（列表 / 文件）；发布（新建 / 删除）；分支（增 / 删 / 改）；提交历史与对比；设置（Pages / CNAME / 危险区）。  
  File browsing with edit-and-commit; issues (create, comment, close); pull requests (list, files); releases (create, delete); branches (create, delete, edit); commit history and compare; repository settings (Pages, CNAME, danger zone).
- **附加 · Extras**：Gist 列表、账户管理、网络与 DNS 设置、应用日志。  
  Gist listing, account management, network and DNS settings, and application logs.

### 安装注意 · Installation note

> **签名 · Signing**：自本版起使用**固定证书**；由旧随机证书构建的安装包请**先卸载再安装**。  
> From this version on, a single fixed certificate is used. Builds signed with the old random certificate must be uninstalled before installing.

Android (arm64-v8a / armeabi-v7a / x86_64 / universal APK / AAB), Windows, Linux, macOS and iOS for all architectures — 18 files in total.
