**主题 · Theme** — 合并 2.1 全部内容（2.1 未产出）+ 多语言框架。
*Folds in everything planned for 2.1 (which never shipped) plus the localisation framework.*

### 新增 · Added（2.1 内容 · from 2.1）

- **全屏代码编辑器 · Full-screen code editor**
  撤销 / 重做、查找 / 替换、换行与字号、未保存拦截、预览高亮；保存走一致性引擎**加锁提交**，冲突可见。  
  Undo/redo, find/replace, soft wrap and font size, unsaved-change interception and highlighted preview. Saves go through the consistency engine’s locked commit, and conflicts are visible.
- **Release 能力补齐 · Complete Release support**
  资产列表与下载、编辑（标签 / 标题 / 说明 / 草稿 / 预发布）、删除、复制说明；新建发布支持“草稿”。  
  Asset listing and download, editing (tag / title / notes / draft / pre-release), deletion and copy-notes; new releases support drafts.
- **Actions**：新增**手动触发工作流**（选工作流 + ref + inputs）；运行详情展示作业 / 步骤的状态、结论与**耗时**。  
  Added manual workflow dispatch (workflow + ref + inputs); run details show each job/step’s status, conclusion and duration.
- **缓存与防误覆盖 · Cache and overwrite protection**
  目录 / 文件读取走底座一致性缓存（短 TTL、可强制刷新）；写入与**删除**均按基线 SHA 加锁，基线过期一律拒绝并提示。  
  Directory/file reads use the base-layer consistency cache (short TTL, force-refreshable); writes and deletes are locked to the baseline SHA and rejected with a hint when it is stale.
- 中文化系统长按菜单（复制 / 粘贴 / 全选）；设置页改为可折叠分组。  
  Localised the system context menu (copy/paste/select all); settings became collapsible groups.

### 新增 · Added（2.2）

- **多语言框架 · Localisation framework**
  zh / zh_TW / en / ja / ko / fr / de / es / pt / ru / ar / hi / th / vi / id；按页面分片（`assets/i18n/<locale>/<page>.json`），缺失键按「当前语言 → 英文 → 键名」三级兜底，绝不空白；中文语境保留 GitHub 术语英文（Issues / Releases / Actions / Pull Requests）。设置页新增「语言」分组，选择后即时生效并持久化。  
  Fifteen locales with per-page shards and a three-level fallback (current locale → English → key name) that never renders blank; GitHub terms stay in English within Chinese copy. Settings gained a language group whose choice applies instantly and persists.

### 工程 · Engineering

- 版本统一：pubspec `2.2.0+20200`，应用内 `kOgLAppVersion = 2.2.0`；发布参数保持必填，全平台注入版本号并带 APK versionName 护栏。  
  Version aligned across pubspec and the in-app constant; release parameters stay mandatory with version injection on every platform and an APK versionName guard.
- 测试：语言包一致性（分片齐全 / 键集合一致 / 中文保留英文术语）。  
  Tests cover locale-package consistency: shards present, key sets identical, GitHub terms preserved.

### 已知限制 · Known limitations

- **当时多语言只是框架**：实际被抽取并翻译的 key 很少（约 66 个，覆盖个位数百分比）；界面文案的完整本地化到 **4.9.0** 才落地。  
  At this point localisation was a framework only — roughly 66 keys were extracted and translated. Complete UI localisation arrived in **4.9.0**.
- 令牌仅存本机安全保险库；仓库数据只与 GitHub 通信。  
  Tokens live only in the device’s secure vault, and repository data is exchanged with GitHub alone.
