## OhGithubLost 4.6.0 · 预发布 / Pre-release（阶段三）

**主题 · Theme** — 手动触发工作流的参数表单、导航切换过渡动画。
*Parameter forms for manually triggered workflows, navigation transition animation.*

### 新增 · Added

- **工作流参数表单（R10）· Workflow input forms (R10)**
  手动触发工作流时读取该工作流 YAML 的 `on.workflow_dispatch.inputs`，把**必选参数 / 默认值 / 选项**渲染成表单（字符串 / 数字 / 布尔 / 下拉选择）；必选缺失会在提交前拦下并提示。保留「高级：直接输入」入口（JSON 或每行 `key=value`）。  
  When triggering a workflow manually, `on.workflow_dispatch.inputs` from the workflow YAML is rendered as a form (string / number / boolean / select) with required flags and defaults; missing required inputs are caught before submission. An “Advanced: raw input” entry (JSON or `key=value` lines) remains available.
- 新增纯 Dart 依赖 `yaml` 用于解析工作流定义。  
  Added the pure-Dart `yaml` dependency to parse workflow definitions.

- **导航切换过渡（R7）· Navigation transition (R7)**
  底部 / 侧边导航切换时加入**左右滑动**入场过渡，保留 `IndexedStack` 的状态与懒挂载；系统关闭动画时瞬时切换。  
  Bottom/side navigation switches now animate in with a horizontal slide while keeping `IndexedStack` state and lazy mounting; with system animations disabled the switch is instant.

### 已知限制 · Known limitations

- **本版本为预发布（pre-release）**，仅供体验验证。  
  This build is a pre-release, published for early verification.
- **多语言（R6）尚未排期落地**：界面仍为中文，其余页面文案抽取体量较大，需单独排期以免产出半成品。  
  Localisation (R6) is not scheduled yet — the UI is still Chinese; extracting the remaining page copy is a large task deliberately deferred to avoid a half-finished, inconsistent release.
- 工作流参数表单不覆盖 `workflow_call` 等其它触发方式。  
  The input form covers `workflow_dispatch` only, not other triggers such as `workflow_call`.
